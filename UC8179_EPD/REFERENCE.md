# 参考实现对比：佳显 / 微雪 / GxEPD2 vs 本库

> 目的：找出为什么本库在边框和白色背景上不如厂商例程干净，并给出可 A/B 的移植方案。

---

## 0. 先排除不适用的参考

| 参考 | 控制器 | 分辨率 | 是否适用 |
|---|---|---|---|
| 佳显 `GDEY0583T81_Arduino` | **UC8179** | 648×480 | ✅ 同芯片同尺寸 |
| 微雪 `EPD_5in83_V2` | **UC8179** | 648×480 | ✅ 同芯片同尺寸 |
| GxEPD2 `GxEPD2_583` | **IL0371** | 600×448 | ❌ 不是同一颗 |
| GxEPD2 `GxEPD2_583_T8` | **GD7965** | 648×480 | ❌ 不是同一颗 |
| GxEPD2 `GxEPD2_583_GDEQ0583T31` | **UC8179** | 648×480 | ✅ 同芯片（最对口） |

佳显和微雪**几乎逐字一致**，可以当成“厂商全刷标准序列”；
GxEPD2 的 `GDEQ0583T31` 是同一颗 UC8179，它的**快刷序列**最有参考价值。

## 1. 初始化对比

| 项目 | 佳显 / 微雪 | 本库（当前） | 差异影响 |
|---|---|---|---|
| 复位 | 硬复位 RST 10ms/10ms | 软复位或硬复位 | 小 |
| PSR `0x00` | `0x1F` | `0x1F` | 一致 |
| PWR `0x01` | **不写**，用 OTP | 写 OTP TR0 值（07/17/3F/3F/12） | 探测已证明无效，可去掉 |
| BTST `0x06` | 不写 | 写 OTP 值 | 同上 |
| TRES/GSST | 不写 | 写 OTP 值 | 一样，无害 |
| CDI 全刷 `0x50` | **`0x21 / 0x07`** | **`0x12 / 0x07`** | **关键差异** |
| CDI 快刷 | `0x29 / 0x07` | — | 厂商快刷用 |
| 快刷 TSSET | `0xE0=0x02, 0xE5=0x5A`（TR6） | `REFRESH_FAST` 用 0x1E（TR4） | 波形不同 |\n| GxEPD2 GDEQ 快刷 | CDI `0x29` + TSSET `0x5A` + **OLD=NEW** | `F` 原来 OLD=白 | 已修正 |
| PON | 上电后 delay 100~300ms 再等 BUSY | 等 BUSY 5s | 等价 |

### CDI 0x21 vs 0x12 到底差在哪

`0x21 = 0010_0001`：

- BDZ=0
- **BDV=10**（边框 LUT 用 LUTWK）
- N2OCP=0
- **DDX=01**（KW 模式，带 NEW/OLD，走 WW/KW/WK/KK 四态）

`0x12 = 0001_0010`：

- BDV=01（边框 LUT 用 LUTKW）
- **DDX=10**（KW 模式，不带 NEW/OLD，只按 NEW 选 LUT）

我们为了省一半数据选了 DDX=10 单平面，但代价是：

- 每个像素每次都按“跳变”波形驱动，**没有 WW/KK 稳态**；
- 白底会被重复驱动，容易留下灰底；
- 边框走 LUTKW（K→W），配合不完整刷新会发灰。

厂商用 DDX=01 双平面，配合 `DTM1=0xFF(白) + DTM2=image`，未变化的像素走 WW/KK，白底和边框能保持干净。

## 2. 数据与刷新对比

| 项目 | 佳显 | 微雪 | 本库 |
|---|---|---|---|
| 全刷数据 | DTM1=`0xFF`，DTM2=image | DTM1=image，DTM2=image | 单平面只发 DTM2；双平面 DTM1=`0x00`(白) |
| 刷新命令 | `0x12` DRF | `0x12` DRF | `0x12` DRF |
| 刷新后 POF | **不 POF**，保持 PON | 不 POF | **每次 POF** |
| 休眠 | CDI=`0xF7` → POF → DSLP | POF → DSLP | POF+DSLP |

注意极性：厂商用 `0xFF=白`，本库实测这块 HINK 是 `0x00=白`（所以 DTM1 填 `0x00`）。
这是玻璃/FPC 差异，**不要把厂商的 0xFF 直接抄过来**，否则整屏反色。

---

## 3. 最可疑的两点

1. **单平面 DDX=10（CDI 0x12）**：没有 WW/KK 稳态，白底和边框更容易脏。
2. **每次刷新后 POF**：电源瞬变会让白态/边框闪一下再回灰；厂商全程保持 PON，只在 DeepSleep 时 POF。

## 4. 已加入的可 A/B 命令（ParamLab）

| 命令 | 作用 |
|---|---|
| `V` | 厂商全刷序列：CDI=`0x21/0x07`，双平面 |
| `F` | GxEPD2 快刷序列：CDI=`0x29/0x07` + TSSET=`0x5A` + OLD=NEW（与 NEW 同图） |
| `U` | 回到本库默认：CDI=`0x12/0x07`，AUTO |
| `K` | 切换“刷新后是否 POF”（保持 PON / 断电） |

### 建议的对比矩阵

| # | 配置 | 操作 | 看什么 |
|---|---|---|---|
| 1 | 本库现状 | `U`，`K` 关闭（即 POF） | 白底、边框基线 |
| 2 | 只改供电 | `U`，`K` 打开 | 白底是否变干净 |
| 3 | 只改 CDI | `V`，`K` 关闭 | 边框/白底是否变干净 |
| 4 | 厂商完整 | `V`，`K` 打开 | 目标效果 |
| 5 | 厂商快刷 | `F`，`K` 打开 | 速度/残影对比 |

每换一组都 `w` 全白 + `k` 画图，观察边框和白底；用 `l` 记 CSV。

## 5. 如果 `V` + `K` 明显更好

下一步就把库的默认改成厂商序列：

- `_p.cdi1 = 0x21`，`_p.cdi2 = 0x07`（双平面）
- `_sendFrame` 走 DTM1(白) + DTM2(image)
- 默认 `_powerOffAfter = false`，在空闲/休眠时再 POF
- 数据量翻倍（每片 +78ms），四片一轮仍可接受

如果 `V` 仍不干净，再考虑：

- 移植厂商的完整寄存器 LUT（PSR.REG=1 + 0x20~0x25），但 GDEY/微雪用的是 OTP LUT，没有 LUT 表可抄；
- 或者接受这块屏的边框极限。

## 6. 关键修正：快刷必须 OLD=NEW

GxEPD2 `GDEQ0583T31` 的 `writeImageForFullRefresh()` 会先把同一幅图写进 `0x10`（OLD），再写 `0x13`（NEW）。
它的 `full_refresh_time = 1200ms`，`useFastFullUpdate = true` 时用 CDI `0x29` + TSSET `0x5A`。

我们之前的 `F` 只把 OLD 写成白色，波形状态和厂商不一致，这是它不能用的最可能原因。
现在 `F` 已改为 OLD=NEW；如果仍不行，再试 `TSSET=0x6E`（GxEPD2 的 partial 档）或回到 `V`。

### 实测：颜色反了，说明 DDX 是极性位

第一次跑 `F` 时画面能出、但黑白反了。原因是：

- 厂商数据约定 **1=白、0=黑**，配合 CDI `0x29`（DDX=01）；
- 本库数据约定 **1=黑、0=白**（HINK 玻璃实测），配合 CDI `0x12`（DDX=10）。

DDX 的 bit0 就是数据极性选择。所以走厂商 CDI（DDX=01）时必须把发送数据整体取反：

- OLD(白) 由 `0x00` 变成 `0xFF`；
- NEW(image) 每个字节 `^0xFF`。

库已在 `_sendFrame()` 里按 `CDI & 0x03 == 0x01` 自动取反，`V`/`F` 不再需要手动 `setInverted()`。
实测 `F`：refresh 1741ms、display 2129ms，画面正常。

### `V` 为什么会在原图上重叠

`V` 原来是 CDI `0x21` + “OLD 补白”。这是假差分：某个像素实际是黑，却告诉控制器 OLD=白，
控制器按 W→W 处理，就不会去清它，于是新图叠在旧图上。

绝对刷新必须 **OLD=NEW**。现在 `V` 已改成 CDI `0x29` + OLD=NEW + 自动温度，
和 `F` 只差一个 TSSET（0x5A）。

### 更彻底：影子帧（真差分）

`OLD=NEW` 仍是“假差分”：未变化的像素走 WW/KK 弱波形，状态并不真实，所以 `V` 还会透出一点残影。

正确做法是 **OLD = 上一帧实际显示的内容**，NEW = 当前帧：

- 变化的像素走强跳变（W→K / K→W），清得干净；
- 未变化的像素走 WW/KK 保持，不闪。

库新增影子帧：

```cpp
epd.enableShadow(true);   // 额外 38,880 字节
```

ParamLab 里按 `H` 开关。开启后第一次刷新仍用白 OLD，第二次开始就是真差分。
四屏时钟每片都要一份影子帧，内存要算进去。

---

## 7. 结论

**值得参考，而且应该参考。** 但只参考佳显/微雪的 **CDI + 双平面 + 保持 PON** 这三点；
GxEPD2 的 583 系列不是同一颗控制器，不能直接移植。

实测结论：开启保持供电（不 POF）后白底明显更干净，所以库默认已改为**保持 PON**；
需要低功耗时用 `setPowerOffAfterRefresh(true)` 显式打开 POF。
